# ui-feedback-loop

화면(UI) 작업을 AI 코딩 에이전트(Claude Code·Codex)와 라운드 단위로 주고받는 스킬입니다.

에이전트가 화면을 고치고 전후 캡처를 찍어 로컬 비교 페이지를 띄우면, 사람은 항목마다 "좋음 / 수정 필요 / 되돌리기"와 메모·이미지 핀으로 평가합니다. 에이전트는 그 평가를 반영해 모든 항목이 "좋음"이 될 때까지 반복합니다.

## 구성

도구는 서브모듈 두 개로 나뉘어 있습니다. 받을 때는 `git clone --recursive` 로 서브모듈까지 받습니다.

- [agent-chat-widget](https://github.com/superego18/agent-chat-widget): 대화창(위젯·대화 서버·세션 연결·앱 프록시·알림)
- [ui-review-page](https://github.com/superego18/ui-review-page): 비교 페이지(페이지·평가 저장·캡처)

이 스킬은 비교 페이지와 채팅 API를 한 도구 서버로 붙여 쓰고(`scripts/review-server.mjs`), 라운드 작업 방식(`SKILL.md`)을 담습니다. 실제 앱·저장 API는 이 도구 서버와 별도 프로세스로 실행합니다.

앱 프록시의 위젯도 이 서버의 채팅 API를 사용합니다. 비교 페이지를 사용하지 않더라도 채팅을 쓰고 있다면 서버 전체를 끄면 안 됩니다. 검토 시작·종료나 캡처 때문에 사용 중인 공유 앱을 재시작하지 않으며, 같은 프로세스에 여러 기능이 있으면 선택 종료 가능 여부와 실제 영향을 먼저 확인합니다. 자세한 기준은 [서버의 수명과 소유권](SKILL.md#서버의-수명과-소유권)을 따릅니다.

## 주요 기능

- **앱 안의 영역 피드백**: 대화창 없이 위치 찍기·화면 번호·자유 메모·전체 시안 목록·편집·삭제·정리본 저장. [연결 안내](docs/annotation-feedback.md)
- **비교 페이지**: 전후 2배 해상도 캡처, 이미지 확대·핀 메모, 캡처 때 잰 번호 상자, 캡처 근거(주소·창 크기·테마·예시 데이터 여부) 표시
- **대화/피드백 창**: 비교 페이지와 실제 앱 화면(앱 프록시)에 같은 창이 붙어, 세션별 탭으로 작업 중인 에이전트와 대화. 터미널 대화도 함께 보임(Claude Code 훅, Codex 대화 기록)
- **상시 대화**: 메시지를 보내면 쉬고 있던 세션이 깨어나 답함(Claude Code 백그라운드 감시, Codex `codex queue`)
- **보관함**: 나중에 보낼 요청을 분류 라벨별로 모았다가 묶어 보내기
- **화면 번호·값 바꾸기**: 보관함 글의 위치를 앱 위에 번호로 보이고, 찍은 요소의 값을 그 자리에서 바꿔 본 뒤 바꾼 값을 함께 보내기
- **두 화면 동기화**: 읽음 상태·쓰던 글·고른 탭·보던 위치·창 크기를 비교 페이지 서버에 두어 앱 화면과 비교 페이지가 함께 씀
- **캡처 레시피와 기록**: 화면별 레시피(주소·예시 응답·조작)로 다시 찍고, 찍은 조건을 기록하고, 오래된 캡처는 확인 뒤 정리

## 설치

Claude Code는 사용자 스킬 폴더에 둡니다.

```bash
git clone https://github.com/superego18/ui-feedback-loop.git ~/.claude/skills/ui-feedback-loop
```

Codex는 `~/.codex/skills/ui-feedback-loop`에 둡니다. 다른 설정 저장소에 서브모듈로 넣어 써도 됩니다.

필요한 것: Node.js 18 이상(의존성 없음), 캡처용 Playwright MCP. 사용법과 라운드 절차는 [SKILL.md](SKILL.md)에 있습니다.
