# 실제 앱의 영역 피드백 연결

- 목적: 실제 시안에서 위치를 찍고 자유 의견을 남긴다. 대화창·보관함·비교 페이지를 거치지 않는다.
- 공용 구현은 기존 `vendor/ui-review-page` 서브모듈에서 관리한다. 대상 프로젝트에 새 Git 서브모듈을 만들 필요가 없다.
- 프로젝트에는 개발용 프록시와 마운트·해제 코드만 둔다. 운영 화면에 자동으로 붙이지 않는다.

## 사용자 흐름

1. `위치 찍기`를 누르고 화면 요소를 누른다. 선택 중에는 앱의 원래 클릭 동작을 차단한다. Esc 또는 취소로 끝낸다.
2. 자유 의견을 적는다. 메모·좋아요·수정 요청·질문 중 분류는 선택 사항이며 위치만 저장해도 된다. `메모 추가`는 위치 없는 의견이다.
3. 저장하면 해당 화면에 번호가 남는다. 번호에 올리거나 키보드로 초점을 주면 범위를 표시하고, 누르면 편집·삭제한다.
4. 같은 화면의 `피드백 N개`에서 전체 시안 목록 또는 현재 화면을 고른다. 다른 시안은 `해당 시안 열기`로 이동한다.
5. `정리본 내려받기`로 Markdown을 받는다. 입력 중인 메모는 같은 브라우저의 로컬 저장소에서 복원한다.

화면 전환·새로고침 때는 글만 복원하고 피드백 창을 자동으로 열거나 초점을 옮기지 않는다. `피드백 N개` 또는 열기 단축키를 직접 눌러 이어 쓴다. 서버 응답보다 먼저 새 메모를 시작한 경우에는 복원으로 현재 편집을 덮어쓰지 않는다.

### 키보드 조작

| 키 | 동작 |
|---|---|
| `Alt+Shift+F` | 피드백 창 열기/닫기. 다시 열면 입력하던 글 또는 목록에 초점 |
| `Alt+Shift+N` | 위치 없는 새 메모. 본문에 바로 초점 |
| `Alt+1~4` | 편집 중 분류 칩: 메모·좋아요·수정 요청·질문. 본문 입력 초점 유지 |
| `⌘/Ctrl+Enter` | 편집 중 저장. 목록 첫 항목으로 초점 이동 |
| `Alt+←` / `Esc` | 목록으로 / 닫기. Esc로 닫은 글은 다시 열어 이어 쓰기 |

- Mac의 Alt는 `⌥ Option`. 칩은 단일 선택 라디오이므로 Tab과 방향키로도 고른다.
- 목록은 ↑↓·Home·End로 이동하고 Enter로 편집한다. 필터·내보내기·삭제도 Tab·Enter로 조작한다.
- 일반 Enter는 본문 줄바꿈을 유지한다. 한글 조합 중·키 반복 중에는 단축키를 실행하지 않는다.
- 전역 열기/새 메모 이외의 단축키는 피드백 창 안에서만 적용한다. 해제 시 키보드 이벤트도 제거한다.

## 서버와 앱 연결

Node.js 18 이상. 프로젝트의 `.ui-feedback/`를 저장 위치로 지정하고 gitignore에 넣는다. 기존 기록을 지우지 않는다.

```bash
node <스킬 경로>/scripts/annotation-server.mjs --dir <프로젝트>/.ui-feedback --port 4797 --origin http://127.0.0.1:3100
```

서버는 `127.0.0.1`에만 바인딩한다. 앱 서버에서 `/__uifb-feedback/:path*`를 `http://127.0.0.1:4797/__uifb-feedback/:path*`로 프록시한다. 브라우저에서 모듈·API·이미지를 앱과 같은 출처로 읽는다. `--origin`은 브라우저에 표시되는 앱 주소와 정확히 맞춘다.

```js
import { mountFeedback } from '/__uifb-feedback/client.js';
const feedback = mountFeedback({
  title: () => document.title,
  active: () => location.pathname === '/beta/ideas',
});
// 앱의 마운트 해제 시
feedback.destroy();
```

동적 모듈 스크립트를 붙이는 호스트에는 로드 후 `window.UiFeedback.mountFeedback`도 제공한다. 개발 모드와 명시적 환경 설정을 모두 만족할 때만 로드한다. 선택적으로 `capture: async () => 'data:image/jpeg;base64,...'`를 전달한다. 캡처 실패는 안내하고 위치·메모 저장은 유지한다. 캡처에서 `[data-feedback-ignore]` 요소를 제외해 피드백 패널이 섞이지 않게 한다.

## 모듈과 저장

| 모듈 | 책임 |
|---|---|
| `dom.js`, `picker.js` | 요소 식별·선택 모드·클릭 차단 |
| `markers.js` | 같은 화면 번호·스크롤 추적·선택 범위 |
| `panel.js`, `style.css` | Shadow DOM 안의 도구 모음·목록·편집·입력 복원 |
| `transport.js`, `client.js` | API 호출·상태 연결·생명주기 |
| `annotation-handler.mjs`, `annotation-store.mjs` | 파일 제공·요청 검증·저장·정리본 생성 |

- `annotations.json`: UUID·연속 번호·분류·본문·URL·화면 이름·작성/수정 시각·선택 위치. 삭제한 번호를 재사용하지 않는다.
- `where`: 표시 이름(`name`)·고정 영역 식별자(`anchorId`)·영역 자체 선택 여부(`exact`)·태그·CSS 선택자·당시 문구·React 컴포넌트 이름(찾을 수 있을 때)·선택 당시 사각형·뷰포트.
- `annotations.md`: 저장·편집·삭제 때 자동 갱신하는 읽기용 정리본. 직접 편집한 내용은 다음 저장 때 덮어쓴다.
- `annotation-images/`: 선택적 PNG/JPEG 캡처. 피드백 삭제 시 해당 이미지도 삭제한다.
- JSON·이미지는 로컬 개발 컴퓨터에 저장한다. 원격 전송·대화 메시지 발송·에이전트 호출은 없다.

## 선택 범위와 한계

- 포인터 아래 실제 DOM 요소를 선택한다. 카드의 빈 여백은 해당 카드, 글자·아이콘은 그 요소가 선택된다. 표도 같은 규칙이다.
- 셀→행→묶음→표 단계 선택, 자유 사각형 드래그는 현재 제공하지 않는다.
- 호스트 앱은 `data-feedback-id`에 값·순서와 독립적인 고정 식별자를, `data-feedback-name`에 사람이 읽는 영역 이름을 붙인다. 반복되는 주문 대상은 주문/상세 ID를 포함한다. 같은 화면에서 식별자는 유일해야 하며 UI 개편 시에도 유지해야 한다.
- 이름 있는 영역 자체를 고르면 고정 식별자로 복원한다. 문구·주변 순서가 바뀌어도 같은 식별자를 찾는다. 삭제·중복 시 다른 위치를 대신 선택하지 않는다.
- 영역 안의 이름 없는 글자·아이콘을 고르면 원래 하위 요소 범위를 유지하며, 영역 아래 상대 구조로 찾는다. 화면에는 구조 기반임을 표시한다. 태그·당시 문구가 달라지거나 선택자가 여러 곳에 맞으면 번호를 숨기고 재확인을 안내한다.
- 피드백 제목은 영역 이름을, 「선택 위치 정보」는 식별자·컴포넌트·당시 값을 보여 준다. 본문 값을 영역 이름으로 취급하지 않는다.
- 예전 기록은 기존 CSS 선택자 방식을 유지한다. 식별자를 추측해 새로 붙이지 않는다. `위치 다시 찍기` 후 저장하면 새 식별 정보를 갖는다. 이름 없는 영역·CSS 구조 기반 위치는 코드 개편 후 영구 보존을 보장하지 않는다.
- 경로와 정렬된 쿼리가 같은 화면에서만 번호를 표시한다. 해시·호스트는 화면 구분에서 제외한다. 접힌 영역·화면 밖 요소는 번호를 숨긴다.
- 서버 한 인스턴스로 한 저장 폴더를 관리한다. 여러 서버가 같은 JSON 파일에 동시에 쓰는 용도는 지원하지 않는다.

## 검증

서브모듈에서 `node --test tests/*.test.mjs`를 실행한다. 대상 앱에서는 위치 선택 시 원래 버튼이 실행되지 않는지, 번호 범위·편집·삭제·새로고침·시안 이동·자유 메모·390px와 1440px 배치를 확인한다. 테스트용 기록만 삭제하고 기존 사용자 기록은 보존한다.

`tests/browser/annotation-restoration.js`는 앱 브라우저에서 실행하는 회귀 검증 함수다. 모듈 프록시가 있는 페이지에서 함수 식으로 평가해 호출한다. 빈 메모·작성 중 메모를 닫은 뒤 패널을 다시 마운트해도 자동으로 열리지 않는지, 글·초점이 보존되고 명시적으로 다시 열 수 있는지 검사한다. 실행 전 로컬 초안은 끝나면 되돌린다.

`tests/browser/annotation-identity.js`는 이름·값 분리, 문구·주변 순서 변경 후 고정 영역 유지, 하위 요소 선택 범위, 중복·삭제·구조 변경 시 잘못된 연결 차단을 검증한다. 피드백 파일을 쓰지 않는다.
